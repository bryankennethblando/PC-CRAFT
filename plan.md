** Dont push on Main **
-- Create a respective branch for each feature
Steps to create a branch:
1. git checkout -b <branch-name>  | example: git checkout main-page

2. git branch | to see which branch you're in it has an * indicator. Example *main or *main-page

3. git pull | always run this command to pull new changes and to avoid merging conflicts

** Create a Pull-Request (PR) **
Do a PR once done on the task

steps:
git add .
git status
git commit -m "<specify the commit>"
git push -u origin <your-branch-name> | Example: git push -u origin main-page

** Note dont push on man and always do a PR **
